## 🎯 Goal

Build strong DSA fundamentals through daily problem solving, understand reusable patterns, and maintain a transparent record of progress.

## ⚡ LeetCode → GitHub Workflow

This repository is designed to work with a LeetCode-to-GitHub synchronization extension.

```text
Solve on LeetCode
       ↓
Submit
       ↓
Accepted ✅
       ↓
Automatic GitHub Sync
       ↓
DSA-Journey repository
```

After the sync tool is connected to this repository, accepted solutions can be pushed automatically. No manual copy-paste is required for normal daily submissions.

LeetCode sync tools generally create one directory per problem using the problem number and title:

Each problem directory can contain the submitted solution, problem information, and metadata generated by the synchronization tool.

## 📈 Practice Principles

1. Understand the problem before coding.
2. Start with a brute-force approach when necessary.
3. Identify the underlying DSA pattern.
4. Optimize time and space complexity.
5. Test edge cases.
6. Submit and verify the solution on LeetCode.
7. Let the GitHub sync record the accepted solution.
8. Review previous problems regularly.

## 🏆 100-Day DSA Challenge

**One problem at a time. One day at a time.**

The objective is not simply to collect submissions, but to develop reliable problem-solving skills and recognize patterns that transfer to technical interviews and real-world engineering.
